# Agent entry point

Before planning or changing this package, read [project context](docs/agents/project.md) and [workflow](docs/agents/workflow.md).

- Before creating, classifying, or scheduling issues or PRs, read [tracker guidance](docs/agents/issue-tracker.md) and [label roles](docs/agents/triage-labels.md).
- Before auxiliary model assessment, service startup, or a permission change, read [model-use policy](docs/agents/model-use.md).
- Before release classification or changelog work, read the workflow's [release policy](docs/agents/workflow.md#versioning-and-releases).

Keep chat bubbles separate from tool rendering, context compaction, editor UI, and terminal configuration. Follow the workflow's documentation-maintenance contract; report documentation impact with delivered changes.
